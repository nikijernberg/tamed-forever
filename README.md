# Tamed Forever

Based on Tamed by moody  
Original repository: https://github.com/moody/Tamed

A WoW: Forever port of the Tamed hunter pet ability guide. The in-game title is **Tamed Forever**.

## Install

Forever beta AddOns path (as of the 1.60.1 / interface 16001 reports):

`World of Warcraft\_classic_beta_\Interface\AddOns\Tamed_Forever\`

If your launcher uses a different folder (`_classic_ptr_`, `retail`, etc.), put `Tamed_Forever` in that client's `Interface\AddOns` directory.

See `INSTALL.md`. The original Tamed ability and NPC databases, plus AceGUI and LibDBIcon, are already in this folder. Do not invent replacement IDs or coordinates.

## Commands

- `/tamed` — toggle the window
- `/tamed clear` — clear map pins
- `/tamed debug` — print diagnostics (not during normal use)
